# 近期操作分析

成交流水 + 估值表 → 行业/个股加减 + 权益敞口变化。**脚本出数字，AI 出解读**，两段职责不混。

## 路径约定（默认值，可被用户指令覆盖）

| 用途 | 路径 |
|---|---|
| 运行配置（产品、窗口、行业覆盖） | `C:\Users\ETT\Playground\infoflowhub\config\portfolio_operations.json` |
| 成交汇总 CSV | `C:\预估值_PB系统\数据\交易系统数据\最近_交易系统汇总数据\历史成交汇总.csv` |
| 估值表根目录 | `C:\预估值_PB系统\产品\<产品>\` |
| 标的信息库（行业一级来源） | `C:\Users\ETT\Playground\infoflowhub\data\reports\标的信息库.json` |
| 产物根 | `C:\Users\ETT\Playground\infoflowhub\data\reports\` |
| 报告 | `<产物根>\操作分析_YYYY-MM-DD.md` |
| 底稿（AI 读它，不读 md） | `<产物根>\操作底稿_YYYY-MM-DD.json` |

产物根固定指向**主 checkout 的 infoflowhub**（数据与运行实例都在主 checkout，不是 worktree）。

## 口径（脚本已固化，勿在对话里临时改）

- **窗口按交易日**：近一周 = 最近 5 个交易日，近一月 = 最近 20 个交易日；交易日取自成交 CSV 自身的日期集合。报告头部会写出实际日期区间，引用数字时连区间一起引。
- **权益敞口 = 股票市值占净值% + 收益互换履约保证金占净值%**。互换底层股票不在估值表内，保证金按 1:1 视为敞口——这是**估算**，实际杠杆未知，输出里必须保留脚注。
- **回购不计入个股加减**（GC001 等），单独统计。
- **成交截至报告日、估值截至上一估值日**，净卖出额与仓位变化不完全对齐属正常。
- **FOF 产品按母基金口径**：金享1号自身净值约 591 万，100% 持有母基金「大朴金享」；个股操作与仓位取母基金。总览表里的「净值」是母基金口径，脚注写明自身规模。
- **行业取标的信息库一级**（`半导体-晶圆代工` → `半导体`）；信息库没有的走 config 的 `industry_overrides`；仍未归类的进底稿 `unresolved`，由 AI 补齐后重跑。

## 流程

| # | 步骤 | 执行者 | 说明 |
|---|---|---|---|
| 1 | 跑脚本 | 脚本 | 读 CSV + 估值表 → 报告 md + 底稿 json |
| 2 | 补未归类行业 | AI | 底稿 `unresolved` 非空时，按公开主营写进 config 的 `industry_overrides`，重跑步骤 1 |
| 3 | 写解读 | AI | 读底稿，把 md 的「解读」占位替换为 3–5 条带数字的结论 |
| 4 | 交付 | AI | 对话里给结论摘要；不改表格里的任何数字 |

> 同日重跑脚本会重置「解读」（脚本只写占位），重跑后需重写；换日运行则是新文件。

**运行命令**（无参数全默认；改脚本后先 `--selftest`）：

```powershell

python "<skill_dir>\scripts\collect_operations.py" --selftest
```

## 阶段二：AI 写作要求

只写 `## 解读` 一节，替换占位注释。硬约束：

- **只引用底稿里的数字**，不自己重算、不四舍五入改口径；引用净额写「万元」。
- **3–5 条，结论先行**，每条必须带数字。建议覆盖：
  1. 本期动作定性（净卖出/净买入、集中度、是否单票驱动）；
  2. 行业层面的方向（加了什么、减了什么，是否结构切换）；
  3. 单票反转（月度加、最近一周减，或反之）；
  4. 异常与待确认（净值与仓位背离、FOF/互换、估值表缺失、未归类标的）。
- **不评价操作对错**：没有成本价与实现盈亏，任何「卖得对/买贵了」都是编造。要评价只能明说「需要成交价与成本基准」。
- **数据风险单列**：净值反推失败、估值表缺失、行业未归类时，在解读末尾写「数据风险」，不要静默略过。
- 不改 `## 口径`、`## 总览`、`## 仓位`、各窗口表格——这些由脚本生成。

## 异常处置

- 成交 CSV 缺失/为空：报错停止，不兜底。
- 某产品在 CSV 里一条都没有：在报告里该产品留空并在解读标注（通常是产品改名或口径变更，先核对 `csv_names`）。
- 估值表某日期找不到：该产品仓位显示「—」并继续，不阻塞；解读里标注。
- 净值反推失败（既无净值行、也没有股票/基金市值占比）：净值显示「—」，不影响净额统计。
- 全部产品都取不到仓位：报告照出，但必须在解读里说明「仓位段不可用」。

## 输出格式

`操作分析_YYYY-MM-DD.md`：口径 → 总览 → 仓位 → 近一周（行业、个股、分产品折叠）→ 近一月（同）→ 解读。

`操作底稿_YYYY-MM-DD.json`：`windows` / `products[].position` / `products[].week|month`（buy/sell/net/repo/industries/stocks/unresolved）/ `total`。AI 只读它，不从 md 反向解析。
