## 韭研公社（jiuyangongshe）订阅源接入

### 背景
新增两个订阅：韭韭八十一（`/u/13da545295e349fc9eb89811b1265b31`）、韭菜团子（`/u/1`）。实测用户主页是 SSR 渲染，**未登录纯 HTTP curl 即可拿到完整文章列表**（标题/链接/日期/摘要），每页15条，翻页 URL 为 `/u/<uid>/page/<n>?keyword=`。

### 决策
- **抓取方式**：纯 HTTP（`urllib`）直抓 HTML 正则解析，不起浏览器、不接认证体系（`auth_key` 留空）。
- **抓取范围**：仅首页15条（配合现有 `trim_entries` 截断逻辑）。
- HTML 结构（已验证）：每篇文章含 `book-title span`（标题）、`fs13-ash` 日期、`href="/a/<id>"`（链接+摘要）。

### 改动清单（5 处文件 + 2 条配置）

**1. 新建 `connectors/jiuyangongshe/feed.py`**
纯 HTTP 抓取器，核心函数：
```python

```
- 注意：函数签名保留 `page` 参数以兼容 `_fetch_via_shared_runner` 调用约定，但内部**忽略 page**，直接用 `urllib` 抓 `site_url`（即 `/u/<uid>` 主页）。
